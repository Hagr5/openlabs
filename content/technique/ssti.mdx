## Overview

Server-side template injection happens when user-supplied text is interpolated into template source instead of passed as data. A renderer that evaluates `{{ expression }}` inside the input runs the expression on the server. Depending on the engine, that leads to property reads, file reads, or code execution.

## Examples

Watch preview, invoice, report, and mail-render features. Send `{{7*7}}`. A response of `49` means the input is template source, and the engine is starting to run what you write.

## FAQ

**Is SSTI the same as a cross-site scripting bug?**

No. XSS runs in a visitor's browser. SSTI runs on the server at the application's privilege level, so the stakes are far higher.

**Do I need special tooling?**

No. A browser or `curl` is enough to detect it. Read [how to play](/play) for the loop.
