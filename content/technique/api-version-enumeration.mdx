## Overview

Improper inventory management means the API catalog is incomplete. The documented version stays current while older versions keep serving traffic, often outside the same review and hardening process. Enumerating `v1`, `v2`, `v3`, or `/api` prefixes surfaces routes nobody told you about.

## Examples

Look for a version marker in the URL (`/api/v3/...`), a header, or a hostname. Step the number down. Compare behavior across versions. A retired version may skip the checks the current one enforces.

## FAQ

**Is version enumeration the same as a shadow API?**

Shadow APIs are one symptom of poor inventory. This page covers the versioned-surface shape: finding a deprecated deployment that should have been retired.

**Do I need special tooling?**

No. `curl` and a scriptable HTTP client are enough. Read [how to play](/play) for the loop.
