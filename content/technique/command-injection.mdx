## Overview

Command injection happens when user-supplied input is concatenated into a string that's passed to a system shell, instead of being passed as a discrete, escaped argument. Shell metacharacters (`;`, `|`, `` ` ``, `$()`) let you append or chain additional commands.

## Examples

Watch for features that shell out to system tools: file conversion, network diagnostics (ping, traceroute-style tools), archive extraction. Try metacharacters in any field that ends up looking like a filename, hostname, or path.

## FAQ

**Is this the same as SQL injection?**

Same family of flaw — unsanitized input reaching an interpreter — but the interpreter here is the OS shell, not a database engine.

**Do I need special tooling?**

A browser or `curl` is enough to start. Read [how to play](/play) for the loop.
