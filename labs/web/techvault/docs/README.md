# Internal Documentation

This directory holds design and security documentation for evaluators
and reviewers only.

**Do not distribute to players** — it contains the full attack walkthrough.

- Design Document (PDF) — challenge metadata, attack family, intended path
- Security Report (PDF) — full solution, root cause, remediation

These documents are intentionally kept inside the lab directory so they
travel with the challenge but are never exposed through the player-facing
GraphQL API.
